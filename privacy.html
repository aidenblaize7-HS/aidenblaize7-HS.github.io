shortsscout Privacy Policy

Last updated: 2026-09-30

What the app accesses

With the channel owner's permission, shortsscout and its uploader (shortsforge-uploader) use these Google scopes, only on channels owned by the same person:

  • youtube.upload: upload the owner's own finished videos to the owner's own channel, after the owner has reviewed and approved each one.
  • youtube.force-ssl: post the owner's own comment (sources for the video) on the owner's own video.
  • yt-analytics.readonly, youtube.readonly: read the owner's own video list and aggregate statistics (views, engaged views, average view percentage).

How the data is used

The statistics are written to the owner's private Notion workspace to compare the performance of the owner's videos. The app does not access viewers' personal information or other channels, does not read viewers' comments, and does not delete anything.

Sharing and storage

Data is not sold, shared with third parties or used for advertising. The OAuth token is stored only as an encrypted secret in the owner's private GitHub repository. Access can be revoked at any time at myaccount.google.com/permissions.

Retention and deletion

Statistics are kept only as long as they are needed to compare the owner's videos and are deleted when the owner stops using the tool. When access is revoked at myaccount.google.com/permissions or through Google security settings, the stored OAuth token stops working and is deleted from the repository secrets within 7 days, together with any stored statistics on request.

YouTube API Services

shortsscout and shortsforge-uploader use YouTube API Services. By using them you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

Google API Services

shortsscout's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements, and to the YouTube Terms of Service.

Contact

Questions: the developer contact email shown on this app's Google sign-in screen.
